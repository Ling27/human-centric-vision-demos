Three studies examine how human-specific priors can guide visual synthesis at progressively finer scales: the complete body, localized facial components, and skin microstructure.

01 · Thesis question

How can controlled changes preserve the human priors that matter at each visual scale?

Generic image generation optimizes semantic correctness and overall plausibility. Human content demands more: small structural or appearance inconsistencies are immediately noticeable.

This thesis treats body, face, and skin as distinct control problems. Each level requires a different representation of what must remain coherent while the target region changes.

Body levelAnatomical coherencePreserve whole-body structure while adding high-resolution local detail.
Face levelComponent compatibilityTransfer selected identity features without breaking the surrounding portrait.
Skin levelSubtle local realismExpress pore-level change without modifying non-pore facial regions.

HRHuman

Tuning-Free Higher-Resolution Human Image Generation

Patch-wise generation gains detail but can fragment the human body. HRHuman uses prompt discretization and template-guided prompt filtering to align each local denoising region with the correct body semantics.

02Face scale

FaceComposer

Reference-Based Coherent and Realistic Face Composition

Selected eyes, eyebrows, nose, or mouth must reflect the reference while remaining compatible with the source face. Component-aware training and boundary supervision improve feature fidelity and transition smoothness without paired ground-truth composites.

Facial Pore Simulation

Realistic Short-Term Skincare Effect Visualization

Clinical observations contain strong daily fluctuations, while pore changes remain small and local. The pipeline combines temporal data cleaning, UNet segmentation, Random Forest regression, and local deformation to simulate change over time.
